# luchshie-casino.github.io

Тестовая страница под кластер **«лучшее казино»** для Яндекса, собранная как применение исследования вёрстки. Одна страница-капсульник: каждая приставка ядра получает свой блок с прямым ответом, фигурой и таблицей.

> ⚠️ **Токен.** Для загрузки использовался GitHub-токен, засвеченный в переписке. Отзови его: GitHub → Settings → Developer settings → Personal access tokens → Revoke. В репозиторий токен не коммитился.

> ℹ️ **Характер.** Демонстрационно-исследовательский проект. Десять профилей в рейтинге — **расчётные примеры методики**, а не реальные сайты; это сказано на первом экране, в подписи таблицы и в футере. Партнёрских и реферальных ссылок нет. Единственная внешняя ссылка — Telegram-канал (тест перелинковки) и реестры двух регуляторов (nofollow).

## Как собиралось (причина → следствие)
1. **Ядро снято живьём из Яндекса** (`SEMANTIC-CORE.md`): подсказки `suggest.yandex.ru`, «люди также ищут», заголовки органики по seed-запросам головы кластера. Голова — «лучшее/лучшие казино»; модификаторы считаются только прикреплёнными к голове. Год в кластере — 2026.
2. **Интент-первая структура:** вердикт-пик → фильтруемая таблица десяти профилей → персоны → капсулы под приставки ядра: выплаты (СБП/карта/USDT), рубли, бонусы (калькулятор вейджера), телефон (андроид/айфон), лицензия (HowTo + схема), отдача (RTP), отзывы, первая сессия.
3. **Механика Яндекса** (`исследование вёрстки для Яндекса/МЕХАНИЗМ-вёрстка-и-ранжирование.md`): один H1 по формуле ключ+выгода, H2 — LSI-спутники (голова только в двух), самодостаточные капсулы под окно внимания, редкие экспертные сущности в каждой (LOK, мастер-лицензии JAZ, MCC/P2P, 115-ФЗ, reverse withdrawal, non-sticky, max cashout, версии RTP, домен загрузки игры), разметка только с DOM-parity: `Article` + `HowTo` (шаги = видимый `<ol>`) + `FAQPage` (тексты = видимые `<details>`); никаких `Review`/`ItemList`/`Organization` для условных названий.
4. **Медиа** — inline SVG на данных: сроки вывода (лог-ось), RTP по играм, схема проверки лицензии, спрайт монограмм, favicon; калькулятор вейджера работает без JS (значения по умолчанию) и с JS (ползунки). Растровые скриншоты реестров и og.png не сделаны: честно их не получить без внешних снимков.
5. **Дизайн-система:** токены light «бумага/медь» и dark «тёплый графит», Literata (opsz) + Golos Text, шкалы кегля/отступов/радиусов/теней, пружинные easing, состояния чипов/таблицы/details/CTA, sticky первая колонка на телефоне, оба режима темы.
6. **Копирайт** без AI-слопа; Ципф-контроль частот на прозе (скрипт в истории сборки).

## Что не выдаётся за факт
Профили условны, поэтому на странице нет «проверено/сверено/замер» о них; вся фактура про регуляторов, лаборатории, провайдеров, платёжные рельсы и налоги — общая и проверяемая.
